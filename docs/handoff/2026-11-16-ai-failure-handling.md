# [확인 요청] 음성 인식·요약 실패 시 서버 처리 방식

- 명세서: https://claude.ai/artifact/5S3Eeyw2TqzhbP7Lx9S3ad
- 작성일: 2026-11-16

@joobogyeong @parkmyeonghun 두 분이 같이 맞춰 주세요!

명훈님 질문: AI(음성 인식·정리·요약)가 실패했을 때 서버가 어떻게 넘어갈지

명세에 이미 있는 것 (오류·예외 처리 탭):
- `STT-FAIL` (음성 인식 실패·무음) → 농가 앱 "글로 쓰기" 화면(F-S02T)으로 전환
- `LLM-FAIL` (정리 실패·형식 오류·8초 초과) → "기록 고치기·선택형 입력" 화면(F-S03E, 분류 9개 버튼)으로 전환
- 모든 AI 오류 형식: `{ code, message, detail }`

정해야 할 것:
- [ ] 서버 타임아웃·재시도 횟수 (예: 1회 재시도 후 오류 코드 반환)
- [ ] `/ai/summary` 실패 시: 전달은 그대로 진행하고, 접수자 화면에는 원본 기록만 보여준 뒤 나중에 다시 생성하는 방식으로 할지
- [ ] 오류 코드별로 서버가 프론트에 넘길 응답 형식

정해지면 이 문서에 결과를 적고 PR 머지해 주세요.
